



# Setup

1. Enter the app folder:

```bash
cd Turing-Test-website-version-2
```

2. Create virtual env:

```bash 
rm -rf venv
python3.12 -m venv venv
source venv/bin/activate
```

3. Install requirements:

```bash
pip install -r requirements.txt
```

# How to run

```bash
python3 app.py
```
